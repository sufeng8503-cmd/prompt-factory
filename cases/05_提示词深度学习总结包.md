## 🚀 使用方法

### 步骤1：写提示词前

1. 打开 **AI视频提示词检查清单.md**
2. 打印或放在屏幕旁
3. 根据场景类型，确定需要哪些要素
4. 填写"提示词模板生成器"

---

### 步骤2：写提示词时

1. 逐项检查清单，打勾 ✅
2. 确保关键要素都包含
3. 参考6大深度学习文档，优化提示词
4. 使用"提示词公式"整合所有要素

---

### 步骤3：生成后

1. 检查生成结果
2. 哪些要素效果好？哪些不好？
3. 调整提示词，再次生成
4. 更新检查清单（在"复盘记录"中）

---

### 步骤4：批量生成（可选）

**方法A：使用batch-generate.js**

```bash
# 批量生成图片
node batch-generate.js --file prompts.txt --type image --ratio 16:9 --count 4

# 批量生成视频
node batch-generate.js --file prompts.txt --type video --ratio 16:9 --duration 5 --fps 24
```

**方法B：手动逐个生成**


## 🎨 分镜图/序列图提示词方法论（2026-05-12 新增）

> 来源：敦煌反弹琵琶舞·16宫格分镜图学习案例

### 核心结构：六维定位法

```
[整体定位] + [场景设定] + [人物设定] + [服装妆造] + [版式要求] + [动作序列]
```

---

### 维度1：整体定位（排除法）

**关键技巧**：使用"不是...而是..."明确边界

```
不是[普通类型A]，也不是[普通类型B]，
而是融合[元素1]、[元素2]、[元素3]的高完成度[最终形态]。

例：
不是普通古风写真，也不是简单舞蹈教学图，
而是融合「敦煌乐舞」「反弹琵琶经典动作」「石窟壁画空间」
「16步编舞分镜」「电影感镜头设计」的高完成度分镜海报。
```

**进阶要求**：
- 每一格既独立成立，又具有连续流动感
- 文化识别度和明显动作层次
- 适合后续作为视频生成分镜参考

---

### 维度2：场景设定（空间质感）

**关键原则**：不要现代舞台，不要空背景，不要摄影棚，不要普通古风室内

**必须包含**：
| 要素 | 示例 |
|------|------|
| 空间类型 | 敦煌石窟前殿/壁画长廊/佛龛光影空间 |
| 墙面细节 | 壁画纹样、拱门、佛龛、石窟肌理 |
| 光影氛围 | 暖金余辉、洞窟暗光、轻微光尘 |
| 主色调 | 赭石、土红、青绿、矿粉蓝、金色 |
| 空间层次 | 前景、中景、后景，层次清晰，具有纵深感 |
| 整体氛围 | 神圣、华美、沉静、带壁画复活感 |
| 画质要求 | 清晰通透，不要浑浊，不要斑点，不要脏污感过重 |

---

### 维度3：人物设定（一致性约束）

**身份定义**：
```
[年龄] + [国籍] + [性别] + [气质描述] + [文化原型]
例：年轻成年中国女舞者，气质端庄、灵动、神圣、优雅，像敦煌乐舞天女
```

**一致性强制约束**（防止AI换脸/换人）：
```
在N格中必须保持：
- 同一张脸
- 同一人物身份
- 同一气质
- 同一套服装体系
- 不要每格像换了一个人
```

---

### 维度4：服装与妆造（文化细节）

**必须细化到可识别**：
| 要素 | 示例 |
|------|------|
| 服装类型 | 高腰长裙、飘逸披帛、敦煌风大袖或轻纱袖 |
| 配色系统 | 赭石、敦煌红、青绿、金色、少量孔雀蓝 |
| 妆造要求 | 发饰与妆面带壁画气质，精致但不浮夸 |
| 核心道具 | 一把琵琶是核心道具，必须清晰可见 |
| 动态要求 | 披帛、裙摆、袖摆都要有真实动态，和身体动作联动 |

---

### 维度5：版式要求（排版逻辑）

```
- 4×4的16宫格排版（或根据需求调整）
- 每格有明显编号1-N
- 每格有中文动作标题
- 每格可有简洁中文说明
- 每格都像一个独立镜头画面
- 可加入轻量动作箭头或轨迹线，增强分镜感
- 整体工整、清晰、信息完整，但不要过度拥挤
- 分辨率要非常高清，人物、道具、背景都清楚可见，不要糊，不要脏，不要有斑点
```

---

### 维度6：动作分镜顺序（编舞逻辑）

**关键原则**：动作要有起承转合，像完整的舞蹈/叙事

**经典结构**：
```
1. 初醒/起势（从静止到动作）
2. 发展（动作展开，逐步升级）
3. 高潮（最完整、最华美的姿态）
4. 归位/定格（回到静止，形成闭环）
```

**示例（16格反弹琵琶舞）**：
```
1.壁画初醒 → 2.抱琵琶起势 → 3-7.侧身/回眸/披帛/献乐/起身/旋抱（发展）
→ 8-13.半旋/反身/反弹/旋身/飞袖/半跪/托乐（高潮铺垫）
→ 14-15.反弹琵琶大定格（高潮）→ 16.壁画归位（闭环）
```

**每格动作描述公式**：
```
[动作名称] + [身体部位] + [具体姿态] + [道具互动] + [情绪/神态]
```

---

### 重点要求清单

- [ ] 必须保持同一舞者一致性（脸/身份/气质/服装）
- [ ] 必须突出核心元素（琵琶、披帛、反身、回旋、献乐、定格）
- [ ] 每一格动作都要明显不同，不能只是拿琵琶摆pose
- [ ] 整体必须写实、华美、敦煌感强、文化识别度高
- [ ] 适合后续作为视频分镜参考

---

### 实战复盘（2026-05-12 验证）

**测试提示词**：大唐独舞·豪华版（宫殿）+ 大唐樱花独舞·春季庭院柔美版

**生成结果分析**：

| 评估项 | 效果 | 说明 |
|--------|------|------|
| 🎯 人物一致性 | ✅ 优秀 | "同一张脸"约束生效，16格舞者脸庞一致 |
| 🎨 场景统一性 | ✅ 优秀 | 每格背景一致（宫殿/庭院），空间感连贯 |
| 🏃 动作差异性 | ✅ 良好 | 每格动作明显不同，起承转合有逻辑 |
| 📋 版式规范性 | ✅ 优秀 | 16宫格+编号1-16+中文标题执行到位 |
| 💃 服装一致性 | ⚠️ 需注意 | 如果提示词不够具体，AI可能在配色上微调——需在「服装与妆造」中写死配色系统 |
| 🎭 神态变化 | ⚠️ 需注意 | 16格舞者神态变化可更加丰富，可追加眼神/表情变化描述 |
| 🌸 环境细节 | ✅ 优秀 | 庭院樱花、宫殿雕梁都有呈现 |
| 🔄 首尾闭环 | ✅ 完成 | 第1格"庭院初现"和第16格"庭院归寂"形成呼应 |

**关键经验总结**：

1. **一致性锁最重要**：16格分镜最大的痛是AI"换人头"——必须在【人物设定】中明确写出"在N格中必须保持同一张脸"，并加粗强调"不要每格像换了一个人"

2. **服装配色要写死**：不能只说"豪华舞服"，要写"朱红+金色+翠绿"或"粉色+白色+嫩绿"的具体配色系统，否则AI会随机配色

3. **动作描述的粒度控制**：
   - 动作名（4字成语类）→ 编号标题（如：旋身·第一转）
   - 动作描述（2-3句话）→ 每格正文
   - 太短→AI自由发挥导致雷同；太长→AI执行不完整
   - **最佳长度：每个动作2-3句描述 + 核心动态关键词**

4. **光影关键词决定氛围**：
   - 宫廷豪华版→"烛光摇曳、金色光影流动、丁达尔效应"→作品氛围华丽
   - 庭院柔美版→"春日柔和阳光、逆光半透明花瓣、柔美光晕"→作品氛围浪漫
   - **光影词汇是氛围的定海神针**

5. **环境排他的重要**："不要...不要..."的排除法句式非常有效，能防止AI跑偏到现代/摄影棚等错误风格

6. **提示词长度与效果正相关**：越完整（6维度全写满），生成效果越好；偷懒省略某个维度，该维度就会翻车

### 维度1：时间戳（节奏锚点）

|------|---------|---------|
