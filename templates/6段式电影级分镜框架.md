## 框架总览

```
1️⃣ 镜头视角 → 2️⃣ 场景设定 → 3️⃣ 主体运动 → 4️⃣ 触发事件 → 5️⃣ 剧情高潮 → 6️⃣ 收尾氛围
```


## 使用方法

**Step 1**：选一个主题（蒸汽朋克/暗黑奇幻/赛博朋克），确定核心主体

**Step 2**：填充6段括号中的占位符，替换为具体内容

**Step 3**：将6段拼接成一个完整的提示词

**Step 4**：粘贴到 AI视频工具（Grok 3 / Seedance / HappyHorse）生成

---

## 框架优势

| 优势 | 说明 |
|:---|:---|
| 分段明确 | 6段各有独立作用，不会混在一起 |
| 可替换性强 | 替换占位符即可切换主题风格 |
| 电影感强 | 每段都有专业的镜头语言描述 |
| 适配AI视频 | 结构清晰，AI容易理解和执行 |
| 三主题示例 | 可直接参考蒸汽/暗黑/赛博三套现成填充 |
